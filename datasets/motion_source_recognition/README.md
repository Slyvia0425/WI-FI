# Module A: motion source recognition

| | |
|---|---|
| Data | CSI-Bench task `MotionSourceRecognition` |
| Source | Kaggle `guozhenjennzhu/csi-bench`, version 12 (see the main README for the link and the citation) |
| Licence | CC BY-NC-ND 4.0 |
| Size | 60,867 files, 9.3 GB (60,858 windows as h5 files, 6 split lists, 3 metadata files) |
| Read by | `backend/modules/motion_source_recognition/preprocessing/`, through `CSI_DATA_ROOT` |

## What it is

60,858 windows of 232 channels by 500 time steps (5 seconds at 100 Hz), recorded in 10 environments (E11 to E20), with the sources
Human (28,154 windows), Pet (26,759), IRobot (4,306) and Fan (1,639). Layout: `metadata/` (sample table, label mapping), `splits/` (the
official lists) and `sub_<class>/user_*/act_*/env_*/device_*/session_*.h5` (one file per window, key `CSI_amps`).

## Get it

```bash
pip install remotezip requests
python3 datasets/motion_source_recognition/get_data.py
export CSI_DATA_ROOT="$PWD/datasets/motion_source_recognition/data/MotionSourceRecognition"
```

`--verify-only` checks files already on disk against the official archive. `sample/` holds 14 original files (3 windows per class and
the label files, 1.7 MB) to see the format; it is not enough to run the pipeline.

## Checked

The copy used in our experiments was compared with the official archive: all 60,867 files are identical (size and CRC32).
All files are used unchanged as input. What the module does with them is in code: the official split puts all 238 recording groups in
both training and test, so three splits by recording group are made, 614 pairs of identical windows are removed, and statistics and
MiniRocket features are computed. The results are regenerated by the code and are not shared as data.
