# K=208 validation error analysis

## Scope

This analysis uses the complete validation split and the frozen seed 123
checkpoint with its fixed threshold 0.054542. It does not use test labels to
select a threshold, feature, or model change. The reproducible detailed output
is generated by `evaluation/analyze_k208.py` under the ignored `outputs/`
directory.

## Main finding

K is confounded with acquisition domain in this dataset. Every K=208
validation sample comes from user U06, environment E10, and 5 GHz. All 1,110
K=208 empty-room samples use deployment `HC_near_Fridge`; other K=208
deployments contain only sleep samples. Therefore the elevated error cannot be
attributed to subcarrier count alone.

The frozen model produces 191 false positives among the 1,110 K=208 empty
samples, an FPR of 17.21%. Those errors account for 191 of all 196 validation
false positives. Difficulty is not explanatory:

| Difficulty | Empty samples | False positives | FPR |
|---|---:|---:|---:|
| Easy | 285 | 48 | 16.84% |
| Medium | 294 | 52 | 17.69% |
| Hard | 531 | 91 | 17.14% |

All eight devices with empty-room samples are affected. Device FPR ranges from
10.71% to 23.38%, so this is not a single faulty receiver. The two highest are
`Hex_1cd6be1df32b` (36/154) and `Hex_1cd6be1df335` (33/145).

## Signal evidence

Interpretable periodicity features were extracted independently from all 1,110
K=208 empty validation windows. Compared with correctly rejected empty
windows, false positives have substantially stronger breathing-band energy:

| Feature | False-positive median | True-negative median | Standardised difference |
|---|---:|---:|---:|
| Maximum breathing-band power ratio | 0.2014 | 0.0869 | +0.77 |
| Q75 breathing-band power ratio | 0.1057 | 0.0604 | +0.70 |
| Median breathing-band power ratio | 0.0797 | 0.0499 | +0.65 |
| Median high-frequency motion ratio | 0.9203 | 0.9501 | -0.65 |
| Median spectral entropy | 0.9085 | 0.9132 | -0.53 |
| Q75 autocorrelation peak | 0.1624 | 0.1397 | +0.34 |

The error windows are more low-frequency, more periodic, and less spectrally
disordered—the same broad characteristics used as breathing evidence. At least
25 false positives have model probability above 0.979, so this is not merely a
cluster sitting just above the low decision threshold.

The most plausible interpretation is periodic appliance/background variation
near the fridge being confused with breathing. This is supported by the signal
features and deployment metadata, but the dataset design does not permit a
causal claim because `HC_near_Fridge`, empty label, K=208, E10, and U06 are
entangled.

## Decision

Do not change the frozen threshold: doing so would trade away breathing recall
and would constitute post-test tuning. Do not add a hard `K == 208` rule,
because K is only a proxy for this acquisition domain and most K=208 samples
are classified correctly.

For the next model version, treat strong stationary appliance-like periodicity
as an uncertainty condition rather than immediately calling it breathing. A
candidate `not_assessable` gate should combine breathing-band concentration,
autocorrelation, cross-subcarrier consistency, and external fan/appliance or
motion evidence. Develop that gate using training/validation data and evaluate
it on a new held-out dataset or newly declared test split—not the already
observed official test set.
